# Digital Wallet

A modern Java-based digital wallet application built with functional programming principles and best practices.

## Overview

Digital Wallet is a Java project designed to provide a robust and scalable wallet management system. The project leverages functional programming paradigms and modern Java features to ensure clean, maintainable, and testable code.

## Technologies & Stack

- **Language:** Java 21
- **Build Tool:** Maven
- **Functional Programming:** [Vavr](https://www.vavr.io/) - Immutable data structures and functional control flow
- **Logging:** SLF4J with Logback for comprehensive logging
- **Code Enhancement:** Lombok for reducing boilerplate code
- **Testing:** JUnit 5 with AssertJ for fluent assertions

## Key Dependencies

| Dependency | Version | Purpose |
|-----------|---------|---------|
| Vavr | 0.10.4 | Functional programming library |
| SLF4J API | 2.0.16 | Logging abstraction |

| Lombok | 1.18.30 | Code generation for boilerplate |
| JUnit 5 | 5.11.4 | Unit testing framework |
| AssertJ | 3.27.7 | Fluent assertion library |

## Features

- **Functional Approach:** Built with Vavr for immutable data structures and functional operations
- **Comprehensive Logging:** Configured with SLF4J and Logback for detailed application insights
- **Well-Tested:** Includes JUnit 5 and AssertJ for robust test coverage
- **Modern Java:** Developed using Java 21 with UTF-8 encoding
